## ✨ Highlights in `v1.0.0`

1. **Clean First-Run Vault Initialization**:
   - New installations start with a completely empty vault (`0` items)—no sample or demo records are seeded.
2. **Full Record Metadata Encryption (`_vz_meta_v2`)**:
   - Record titles, categories, and tags are encrypted inside the `AES-256-GCM` ciphertext payload and redacted (`[REDACTED]`) in raw SQLite columns and `.vzero` backup containers.
3. **Per-Record GCM AAD Row Binding**:
   - Every record's `AES-256-GCM` authentication tag is bound to `VaultZero-Record-v2|<id>|<type>|<createdAt>|<updatedAt>|<isFavorite>`, preventing cross-row ciphertext substitution attacks.
4. **Dual-Envelope 256-Bit Vault Master Key (VMK)**:
   - A 256-bit random VMK encrypts all vault records and is wrapped independently by your **Master Password KEK** and **12-Word SHA-256 Checksummed Recovery Phrase KEK** using `PBKDF2WithHmacSHA256` (**100,000 iterations**).
5. **Hardware-Backed Biometric Unlock**:
   - Uses Android Keystore `AES/GCM/NoPadding` hardware-bound keys (StrongBox preferred) with `BiometricPrompt.CryptoObject`.
6. **Portable `.vzero` Encrypted Backups**:
   - Export and import self-contained encrypted `.vzero` vault files across devices using either your Master Password or 12-Word Recovery Phrase.
7. **Strict Air-Gapped & Runtime Security**:
   - Zero internet permissions (`INTERNET` and `ACCESS_NETWORK_STATE` stripped via manifest merger rules), disabled OS cloud auto-backup (`android:allowBackup="false"`), `FLAG_SECURE` screen-capture blocking, sensitive clipboard masking with 30-second auto-clear, and optional 5-strike Panic Wipe.
