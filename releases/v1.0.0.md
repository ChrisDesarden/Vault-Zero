## ✨ Highlights in `v1.0.0`

### 1. Clean-Slate Zero-Knowledge Initialization
- **Empty Vault on First Install**: New installations start completely clean with zero pre-populated sample items, ready immediately for production personal or team use.
- **Dual-Envelope Key Wrapping**: Generates a cryptographically random 256-bit **Vault Master Key (VMK)** via `java.security.SecureRandom`, wrapped independently by your **Master Password KEK** and a **12-Word SHA-256 Checksummed Recovery Phrase KEK** (`PBKDF2WithHmacSHA256`, 310,000 iterations).

### 2. Full Record Metadata Encryption (`_vz_meta_v2`) & GCM AAD Row Binding
- **Zero Plaintext Metadata Leakage**: Record titles, categories, and tags are serialized inside the AES-256-GCM ciphertext payload and stored as `[REDACTED]` in the underlying SQLite table (`vault_items`) and `.vzero` backup files.
- **Anti-Tamper Row Binding**: Every record binds `VaultZero-Record-v2|<id>|<type>|<createdAt>|<updatedAt>|<isFavorite>` as Additional Authenticated Data (AAD) into the 128-bit GCM authentication tag, preventing ciphertext swapping across rows.

### 3. Hardware-Backed Biometric Unlock
- Uses Android Keystore (`AES/GCM/NoPadding`, StrongBox hardware security module preferred when present) with `BiometricPrompt.CryptoObject` to unwrap the Vault Master Key only after hardware-verified biometric authentication.

### 4. Built-in Authenticator, Security Audit & Portable `.vzero` Backups
- **RFC 6238 Live TOTP Generator**: Real-time 6-digit 2FA codes with a 30-second visual countdown ring inside Login records.
- **Security Audit Dashboard**: Offline entropy evaluation, reused/weak password detection, 2FA coverage score, and aging credential alerts (>180 days).
- **Encrypted `.vzero` Backup & Restore**: Export and import self-contained encrypted vault snapshots via Android's zero-permission Storage Access Framework (SAF).
